## One-Sentence Task

**Given the text of an HTTP request captured from network traffic, I will train a model to classify it as benign or potentially malicious.**


## Illustrative Input and Desired Output

- **Example input:**The input is the text of one HTTP request (here, a TCP port 80 POST request):

   POST /tienda1/publico/anadir.jsp
   id=1&nombre=Queso+Manchego&precio=39&cantidad=57&B1=A%F1adir+al+carrito
- **Desired output:** The model returns a label and a confidence score:
    {
      "prediction": "benign",
      "confidence": 0.97
    }

## Preferred Data

### Corpus

The proposed corpus is HTTP Dataset CSIC 2010, The dataset was built at the Information Security Institute of CSIC The traffic was automatically generated against an e-commerce web application built by the research group itself. Attack traffic was generated by tooling aimed at that same app. This also means no real users’ data is involved (https://www.kaggle.com/datasets/ispangler/csic-2010-web-application-attacks) which is a large zip file full of plain text files of raw HTTP requests. The analysis will be labeling if the request is normal or anomalous. I will use the method, URL, and POST body, joined into one text string, plus the label. The estimated size is roughly 36000 normal requests and 25000 anomalous ones.
